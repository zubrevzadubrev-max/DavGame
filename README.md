# DavGame

DavGame — игровая веб-платформа с шахматами и русскими шашками. Проект полностью статический, адаптирован для GitHub Pages и не требует сборщика.

## Возможности

- локальный профиль с аватаром и сохранением в `localStorage`;
- две интерактивные игры против бота с уровнями сложности;
- тренировочные задания, очки, статистика и история партий;
- адаптивный интерфейс для телефона, планшета и компьютера;
- собственные уведомления и подтверждения опасных действий;
- онлайн-комнаты для шахмат и шашек через Firebase Realtime Database.

## Игры и режимы

Доступны шахматы и русские шашки. Для каждой игры предусмотрены режимы «с ботом», «онлайн-комната» и «задания». Локальные режимы работают сразу. Синхронизация онлайн-комнат требует собственного бесплатного проекта Firebase.

## Локальный запуск

Откройте `index.html` через локальный сервер. Например, в VS Code используйте Live Server или выполните `npx serve .`. Прямое открытие файла может блокировать ES-модули в некоторых браузерах.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**.
4. Укажите ветку `main` и папку `/ (root)`, затем сохраните.

Все пути в проекте относительные, поэтому сайт корректно работает из подпапки GitHub Pages.

## Подключение Firebase и настоящих онлайн-комнат

1. Откройте [Firebase Console](https://console.firebase.google.com/) и нажмите **Create a project**. Google Analytics для учебного проекта можно отключить.
2. В **Project Overview** нажмите значок **Web (`</>`)**, задайте имя приложения `DavGame Web` и зарегистрируйте его. Firebase Hosting включать не требуется: сайт остаётся на GitHub Pages.
3. Откройте **Build → Authentication → Get started → Sign-in method** и включите провайдер **Anonymous**. Он выдаёт каждому браузеру отдельный безопасный `uid` без формы регистрации.
4. Откройте **Build → Realtime Database → Create Database**. Выберите ближайший к пользователям регион; после создания регион изменить нельзя. Для Узбекистана обычно выбирают доступный европейский регион с минимальной задержкой.
5. Создайте базу в locked mode. Затем откройте вкладку **Rules**, вставьте содержимое файла `firebase.rules.json` и нажмите **Publish**.
6. Перейдите в **Project settings → General → Your apps → DavGame Web → SDK setup and configuration → Config**.
7. Скопируйте значения `apiKey`, `authDomain`, `databaseURL`, `projectId`, `storageBucket`, `messagingSenderId`, `appId` в объект `firebaseConfig` внутри `js/firebase-config.js`.
8. В **Authentication → Settings → Authorized domains** добавьте домен GitHub Pages, например `username.github.io`. `localhost` можно оставить для локальной проверки.

Проект использует браузерные ES-модули Firebase SDK 12.19.0: `firebase-app`, `firebase-auth` и `firebase-database`. Node.js backend не нужен. Без доступной базы Firebase локальные игры, задания, профиль и статистика продолжают работать.

### Правила безопасности

Файл `firebase.rules.json` разрешает чтение путей комнат только пользователям, вошедшим через Firebase Authentication. Это необходимо, чтобы клиент мог проверить свободен ли случайный код `DAV-XXXX` до создания комнаты. Запись разрешена создателю, подключающемуся guest и участникам комнаты; структура, тип игры, статус и профиль валидируются. Это существенно безопаснее полностью открытых правил вроде `".read": true, ".write": true`.

Правила проекта остаются клиентскими: участник комнаты технически может подменить игровой объект через инструменты разработчика. Для рейтингового или коммерческого проекта дополнительную валидацию ходов следует вынести в доверенную среду, например Cloud Functions.

### Проверка мультиплеера

1. В обычном окне создайте первый профиль, откройте игру → **Онлайн-комната** → **Создать комнату** и скопируйте `DAV-XXXX`.
2. В режиме инкогнито создайте другой профиль, откройте ту же игру, вставьте код и подключитесь.
3. Проверьте, что оба игрока и статус `LIVE` появились без перезагрузки.
4. Сделайте по одному ходу в каждом окне и убедитесь, что позиция и очередь меняются одновременно.
5. Проверьте сдачу, ничью, реванш и выход из комнаты.

Для публикации после настройки повторно загрузите в GitHub `js/firebase-config.js`, `js/rooms.js`, `js/online-games.js`, `firebase.rules.json` и остальные изменённые файлы проекта. Сам `firebase.rules.json` GitHub Pages не применяет — правила нужно отдельно опубликовать в Firebase Console.

## Структура

- `index.html` — оболочка приложения;
- `css/` — визуальная система и адаптивность;
- `js/app.js` — маршрутизация и экраны;
- `js/chess.js`, `checkers.js` — локальные игровые режимы;
- `js/rules.js` — общие правила шахмат и русских шашек для локальной и онлайн-игры;
- `js/rooms.js` — Firebase Authentication, комнаты, presence и транзакции;
- `js/online-games.js` — realtime-доски и проверка сетевых ходов;
- `js/storage.js` — локальные данные и статистика;
- `js/ui.js` — уведомления и модальные окна;
- `js/firebase-config.js` — конфигурация онлайн-функций.
- `assets/logo.svg`, `logo-mark.svg`, `favicon.svg` — фирменный знак DavGame;
- `firebase.rules.json` — рекомендуемые правила Realtime Database.
